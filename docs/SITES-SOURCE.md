# Alwadani — منصة الدروس

موقع تعليمي عربي يدعم الصفوف من الأول الابتدائي إلى الثالث الثانوي، مع شرح وتمارين وتصحيح مفسر ولوحة نتائج وشهادة إتمام. الطلاب يبدأون بالاسم فقط. مساحة المعلم خاصة بمالك الموقع.

## الروابط والإدارة

- الموقع: https://alwadani-grammar-lab-2026.jubranii45.chatgpt.site
- إدارة الدروس: https://alwadani-grammar-lab-2026.jubranii45.chatgpt.site/teacher
- الثالث المتوسط: https://alwadani-grammar-lab-2026.jubranii45.chatgpt.site/?grade=grade-9

من لوحة الإدارة يمكنك إضافة الدروس وتعديل الشرح والتمارين والإجابات وأسباب التصحيح واختيار الصف، ثم الحفظ كمسودة أو النشر. لتحويل درس منشور إلى درس مخفي، احفظه كمسودة. زر تنزيل نسخة الدروس يحفظ المحتوى المحفوظ لكل الدروس، بما في ذلك المسودات.

## ماذا تملك هذه النسخة؟

هذه نسخة من ملفات المصدر القابلة للتعديل، إعدادات البناء، ملفات تعريف قاعدة البيانات وملفات إنشاء الجداول، ودليل التشغيل. درس حكايات الماضي الأصلي والشرح الإضافي وروابط الفيديو محفوظة في المصدر. لا تتضمن النسخة كلمات مرور أو أسرارًا أو قاعدة بيانات الإنتاج.

توجد ثلاثة أشياء مستقلة:

| الشيء | أين يوجد؟ | كيف تحتفظ به؟ |
| --- | --- | --- |
| كود الموقع | هذا المشروع ومستودع المصدر الخاص بـ Sites | ملف المصدر ZIP، ثم مستودع GitHub خاص إن رغبت |
| الدروس التي أضفتها من لوحة الإدارة | جدول courses في قاعدة البيانات | زر تنزيل نسخة الدروس في لوحة الإدارة، بصيغة JSON |
| الطلاب والإجابات والتقدم | جداول students وanswers وreads | تحتاج نسخة مستقلة من قاعدة الإنتاج إذا أردت نقل النتائج إلى استضافة أخرى |

تنزيل الكود وحده لا ينقل بيانات الطلاب أو الدروس المضافة لاحقًا. تنزيل الدروس لا ينقل درجات الطلاب. يمكن إرسال ملف الدروس هنا للمساعدة في استعادته؛ لا يوجد استيراد تلقائي من الملف في الواجهة الحالية. الطالب يتابع تقدمه عبر ملف تعريف خاص في المتصفح نفسه؛ كتابة الاسم نفسه على جهاز آخر لا تستعيد الجلسة القديمة.

## تشغيل نسخة على جهازك

المتطلبات: Node.js 22.13 أو أحدث وpnpm 11.25.0 كما هو محدد في package.json. هذه التعليمات لنسخة جديدة على جهازك، ولا تعدل الموقع المنشور.

1. فك ملف ZIP وافتح الطرفية داخل مجلد المشروع.
2. ثبّت الحزم من ملف القفل:

```sh
pnpm install --frozen-lockfile
```

3. جهّز قاعدة محلية. الأمر التالي يطبق ملفات drizzle بترتيبها ويسجل ما طُبّق، ويمكن تشغيله مرة أخرى لتطبيق ملفات جديدة:

```sh
node scripts/local-database.mjs
```

4. أنشئ ملفًا محليًا اسمه .dev.vars وأضف إليه هذا السطر ليتوافق مع حساب المعلم التجريبي على جهازك:

```text
TEACHER_EMAIL=seedy@sites.test
```

هذا الحساب خاص بتجربة التطوير على جهازك. النسخة المنشورة تستخدم حساب المالك الحقيقي عبر إعداد سري، وليس هذا الحساب.

5. ابدأ التطوير:

```sh
pnpm dev
```

افتح العنوان الذي يظهر في الطرفية، ثم /teacher. في النسخة المحلية النظيفة تستخدم صفحة الدخول حساب تطوير افتراضيًا. ملف .dev.vars وبيانات .wrangler لا ترفع إلى GitHub.

6. للتحقق من الأنواع وبناء نسخة تشغيل محلية:

```sh
pnpm exec tsc --noEmit
pnpm build
pnpm start
```

تعليمات الإطار الأصلي والتفاصيل الإضافية محفوظة في docs/STARTER.md. التعليمات المحلية تفترض أن النسخة الجديدة لا تحتوي على .sites-runtime؛ لا تنسخ إعداد تشغيل بيئة ChatGPT إلى جهازك.

تعديل عنوان الدرس أو الصف لا يلغي تقدم الطلاب. عند تعديل محتوى التمارين يحتفظ من بدأوا الحل بنسختهم السابقة، ويبدأ الطلاب الجدد بالمحتوى الجديد. ترتيب الخيارات يختلف بين جلسات الطلاب ويظل ثابتًا في جلسة الطالب عند إعادة التحميل أو متابعة الدرس. تُحفظ الإجابات في ترتيبها الأصلي على السيرفر حتى تبقى الدرجات القديمة والمقارنة في لوحة النتائج صحيحة.

## الاحتفاظ به في GitHub

المشروع الحالي محفوظ في مستودع مصدر Sites، ولم يُربط بحساب GitHub. لرفع نسخة مستقلة، أنشئ مستودعًا فارغًا خاصًا في حسابك ثم نفذ الأوامر التالية داخل المجلد المستخرج، مع استبدال رابط المستودع برابطك:

```sh
git init
git add .
git commit -m "Initial Alwadani learning platform"
git branch -M main
git remote add origin https://github.com/YOUR-ACCOUNT/alwadani-learning.git
git push -u origin main
```

ملف .gitignore يستبعد الحزم والأسرار وبيانات التشغيل المحلية. هذه الخطوة تحفظ الكود وتاريخه؛ لا تربط نشر موقع Sites تلقائيًا بهذا المستودع ولا تنقل قاعدة بياناته. عند إجراء تغيير هنا يمكن نشره على موقعك الحالي وتحديث النسخة التي تحتفظ بها.

## قاعدة البيانات الحالية

الموقع المنشور يستخدم Cloudflare Workers مع قاعدة Cloudflare D1 مربوطة باسم DB. مفعّلة بالفعل ولا تحتاج إلى إنشاء قاعدة إضافية للميزات الحالية. بيانات الجلسات والدرجات محفوظة على السيرفر؛ ملف المتصفح يحدد جلسة الطالب فقط.

- courses: الدروس المنشورة والمسودات وتصنيفها.
- students: جلسات الطلاب، الاسم، الدرس، حالة الإتمام ونسخة المحتوى وقت بدء الحل.
- answers: الاختيارات الأولى والنتائج.
- reads: محطات الشرح التي قرأها الطالب.

إذا أردت الاطلاع على الجداول الحالية، افتح إعدادات الموقع في Sites ثم عارض قاعدة البيانات إن كان ظاهرًا في واجهتك. هذه قاعدة تديرها استضافة Sites؛ ليست تلقائيًا قاعدة ضمن حساب Cloudflare الشخصي الخاص بك.

## إعداد قاعدة جديدة على Cloudflare الخاص بك مستقبلًا

هذه خطوات للمطور عند الانتقال إلى استضافة مستقلة، وليست مطلوبة لموقعك الحالي:

1. سجّل الدخول إلى حساب Cloudflare باستخدام Wrangler وأنشئ D1 جديدة:

```sh
pnpm exec wrangler login
pnpm exec wrangler d1 create alwadani-learning
```

2. أضف إلى إعداد Worker المستقل ربط d1_databases باسم DB ومعرّف القاعدة الذي أعاده الأمر، واضبط migrations_dir على مسار drizzle. إعداد vite.config.ts الحالي يستخدم معرفًا تجريبيًا للمعاينة فقط؛ يجب استبداله بإعداد الإنتاج الجديد ضمن عملية نقل كاملة، وعدم نشر المعرف التجريبي.
3. طبّق ملفات إنشاء الجداول على القاعدة الجديدة باستخدام إعداد Worker الذي جهزته:

```sh
pnpm exec wrangler d1 migrations apply DB --remote --config PATH-TO-YOUR-WORKER-CONFIG
```

4. انقل محتوى الدروس والبيانات المطلوبة من نسخة القاعدة، وجهّز إعداد TEACHER_EMAIL كسر في الاستضافة الجديدة.
5. استبدل آلية تسجيل دخول المعلم: الإصدار الحالي يعتمد على هوية موثوقة تضيفها استضافة Sites. على استضافة مستقلة تحتاج إلى آلية تسجيل دخول تتحقق من الهوية على السيرفر وتستبعد رؤوس الهوية التي قد يرسلها الزائر. لا يكفي نقل قيمة بريد المعلم أو الاعتماد على رؤوس يرسلها المتصفح.

رفع الملفات إلى GitHub أو Cloudflare وحده لا ينقل بيانات الإنتاج ولا يجهز تسجيل دخول المعلم. راجع الخطوتين الأخيرتين قبل نشر نسخة مستقلة للطلاب.

مراجع Cloudflare الرسمية:
- أوامر D1: https://developers.cloudflare.com/workers/wrangler/commands/d1/
- ملفات التغييرات: https://developers.cloudflare.com/d1/reference/migrations/
- الأسرار: https://developers.cloudflare.com/workers/configuration/secrets/

## حدود النسخة وحقوق المكونات

المشروع يستخدم React وTypeScript وVinext وCloudflare D1. ملف القفل يثبت نسخ الحزم. توجد ملفات تراخيص للمكونات الموردة في build/ وvendor/، ويجب الاحتفاظ بها عند إعادة توزيع الكود. فيديوهات يوتيوب روابط خارجية وليست ملفات مملوكة أو مضمنة في نسخة المصدر.
